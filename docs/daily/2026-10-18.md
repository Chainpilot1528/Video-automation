## 1. Phase 7: the first rendered video (`601822a`)

- **Timeline compiler:** turns the project files into a render plan, without running FFmpeg.
  - Scene length = 0.25 s lead-in + **measured** narration + 0.5 s tail.
  - Fades happen inside each scene, so there are no overlaps to double-count.
- **FFmpeg renderer:** renders each scene separately and **caches** it, so changing one scene re-renders only that scene.
  - Every output is checked with ffprobe before it's used.
  - A render report records the exact commands and file checksums.
  - On failure, logs are kept and the next run resumes from the scenes that already succeeded.
- **Profiles:** `preview` (960×540, fast) and `master_16x9` (1080p; refuses placeholders and missing narration).
- **New commands:** `timeline build`, `render preview`, `render master`, with `--burn-captions` and `--dry-run`.
- **Bugs found and fixed while testing:**
  - Changing how captions are drawn reused old cached scenes. The renderer's own code is now part of the cache key.
  - A corrupt image made FFmpeg hang for over 9 minutes. Inputs are now test-decoded first, and every FFmpeg call has a time limit.
  - Captions were hard to read over graphics, so they now sit on a dark box.
- **Important fix:** a `.gitignore` rule had been hiding `src/reckoning_pipeline/media/` since Phase 5, so earlier commits were missing two source files. This is fixed from `601822a` onward.
- **Result:** a 36-second demo preview video, rendered in about 12 seconds.
